# Phase 0 Skills Checklist

Use this as a practical skills audit.

## Asset management

- [ ] Identify all VMs
- [ ] Determine VM state
- [ ] Identify VM resources
- [ ] Identify VM interfaces
- [ ] Map MAC addresses to interfaces
- [ ] Map interfaces to networks

## Network fundamentals

- [ ] Interpret IPv4 subnetting
- [ ] Identify network/broadcast addresses
- [ ] Understand default gateways
- [ ] Understand DHCP
- [ ] Understand NAT
- [ ] Read routing tables
- [ ] Read ARP/neighbour tables
- [ ] Understand bridge interfaces

## Troubleshooting

- [ ] Test local gateway connectivity
- [ ] Test host-to-host connectivity
- [ ] Compare routing decisions
- [ ] distinguish local delivery from routed traffic
- [ ] investigate failed connectivity
- [ ] distinguish a powered-off host from a network failure
- [ ] record evidence before changing configuration

## SOC/NOC operational skills

- [ ] Build an asset inventory
- [ ] Build a connectivity matrix
- [ ] Establish a known-good baseline
- [ ] Identify deviations
- [ ] Document observations
- [ ] Keep raw evidence
- [ ] Produce a concise technical report
- [ ] Explain findings clearly to another analyst

## Professional practice

- [ ] Use reproducible commands
- [ ] Timestamp evidence
- [ ] Preserve original evidence
- [ ] Avoid unnecessary changes
- [ ] Record assumptions
- [ ] Record limitations
- [ ] Explain what evidence proves and does not prove
